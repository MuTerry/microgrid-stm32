# STM32 微电网控制项目

基于 NUCLEO-F446RE，实现 CAN 功率指令接收、四路 PWM 控制、模拟量采样和电流 PI 控制，逐步接入真实传感器与 Buck 功率级。

**进度更新：2026-10-20**

**固件基线：`153e2b0`**（CAN、PWM、双 ADC 与电位器反馈 PI 台架测试）

**当前观察固件：`2cbbc6e`**（PA1 原始 ADC 观察模式；10 月 20 日仅更新测试记录）

当前阶段：**静态分压与 ADC 对应关系已核对，正向小电流基础响应及回零已观察到；正在复核反向电流下的万用表/ADC 一致性。正式零点、灵敏度标定、精度验证和真实功率 PI 收敛尚未完成。**

当前源码默认 `ADC_RAW_TEST_MODE=1`：只采 PA1、四路 PWM 保持为零、暂停 `0x200` 发送，串口每约 250 ms 输出原始 ADC 数据。下面列出的 CAN 测量反馈和电位器 PI 为既有基线验证结果，不代表观察模式正在执行这些功能。心跳接收与超时锁存仍运行。

- [x] 接收 `0x100` 功率指令、`0x102` 光伏/风电指令和 `0x101` 心跳，发送 `0x200` 状态反馈。

- [x] 光伏单路 PI 的电位器反馈方向与限幅测试；其余三路当前仍为开环控制。
- [x] 心跳超时保护：超过 1000 ms 未收到有效心跳，关闭全部 PWM、置故障码 5 并锁存，手动复位恢复。

**心跳超时关闭并锁存是当前明确保留的行为。总路线资料中的下垂控制不作为当前固件行为。**

结合模块资料及断电电阻测量，**推断 OUT1 为直接/滤波输出，OUT2 为运放缓冲输出**。尚未完整追踪 PCB 原理图，CJMCU-758 资料与 HW-525 实物也存在版本差异，不能把输出编号对应关系视为完全确认。两路测试结果支持近似相同的直流增益。

本次测得的零点及粗估灵敏度仅用于基础功能判断，尚不是正式标定参数。早期模块与负载共用台式电源的测试数据不用于标定。上述模块独立测试阶段未修改、编译或烧录固件。

### 分压接入记录（2026-10-17）

- [x] 搭建 OUT2 → R1（10 kΩ）→ A；A 经 R2（10 kΩ）接信号地，经 R3（1 kΩ）接 B；B 经 100 nF 电容接信号地。
- [x] B 未接 PA1 时，最后一轮零电流测得模块 VCC=4.973 V、OUT2=2.495 V、B=1.2453 V，静态分压比约 0.49912。
- [x] B 已接 PA1，用户报告 PA1 对地电压为 1.2377 V。两次读数并非同步测量，不能据此直接判断接入造成的压降。

电阻最初在面包板电路中测得 8.884/8.884/1.0077（按 kΩ 理解）；取出后用户报告 10.0013 kΩ。该读数尚未逐一对应 R1/R2，正式标定前应分别记录两只分压电阻的独立测量值。当前不把在电路中的读数用于计算精确分压比。

早期测量曾记录 VCC 约 4.494 V，与最后一轮 4.973 V 不一致，原因未确认；不改写早期记录，也不混合各轮数据标定。静态分压验证不代表完整故障保护验证。

### 静态电压与电流响应复核（2026-10-20）

- [x] 一组同轮静态数据中，OUT2=2.380 V、PA1=1.1909 V，分压比约 0.50038；用开发板实测 3.291 V 近似参考电压，`avg=1480` 对应约 1.1894 V，相差约 1.5 mV。
- [x] 正向 +0.484 A 时，相对本轮前后零点平均值，PA1 上升 9.8 mV、ADC 增加 12 个计数；撤载后回到初始值附近。
- [x] 反向 −0.490 A 时，PA1 和 ADC 均下降，方向符合预期。
- [ ] 反向幅度一致性：PA1 实测变化 −5.9 mV，ADC 变化 −12.5 个计数；若参考电压约 3.29 V，后者约对应 −10.0 mV。仍需本轮参考电压与同步读数复测。

串口曾无法打开、随后恢复，具体恢复原因未确认。用户曾报告移动开发板会改变读数并伴随 STM32 明显发热；在铁质桌面上改为绝缘放置并固定接线后，报告未再明显发热。怀疑板底接触金属造成间歇短路，未直接测得故障点，不能写成已确诊或已完成损伤排除。后续保持绝缘支撑和固定接线。

不同轮次零点及模块供电发生变化，不混用零点，也不将单点灵敏度粗估写入固件。完整人工记录、计算和待复测步骤见 [10 月 20 日测试报告](docs/tests/2026-10-20-pa1-current-response.md)。

### 当前观察固件

- USART2：115200、8N1；每组采 32 次，输出 `avg/min/max/mV/n/err/safe/fault`。
- `mV` 使用暂定参考电压 3300 mV，表示 PA1 电压，不是 OUT2 电压或真实电流。
- 观察模式在初始化后将 ADC1 改为单通道 PA1，避免轮询读取双通道扫描时的数据覆盖；CubeMX `.ioc` 保留原双通道基线配置。
- 没有 CAN 心跳时，约 1 s 后出现 `HEARTBEAT TIMEOUT`、`safe=1 fault=5`，原始值观察仍继续；心跳恢复不会清除锁存，需手动复位。
- 当前模式屏蔽 CAN 功率指令对 PWM 的写入，不运行 PI，不发送仍含电位器换算的 `0x200`。

`ADC_RAW_TEST_MODE=0` 仅恢复旧电位器台架逻辑，不能用来启用 ACS758 真实闭环。当前阶段尚未加入零点标定或真实电流换算。

## 正在做

**复核反向电流加载时的万用表/ADC 幅度一致性。**

沿用反向回路、约 10 V / 0.6 A 限流设置，先测本轮加载时开发板 3V3，然后固定表笔在 PA1，每隔约 5 s 同步记录 PA1 电压与 ADC `avg`，共三组，最后关闭负载。上述复测尚未收到数据。

此前开发板 3V3=3.291 V 的读数不直接沿用为本轮参考电压。串口 `mV` 仍按名义 3300 mV 计算，未修改换算系数；模块与开发板共地、PWM 不接功率级。
