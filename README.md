# STM32 微电网控制项目

基于 NUCLEO-F446RE，实现 CAN 功率指令接收、四路 PWM 控制、模拟量采样和电流 PI 控制，逐步接入真实传感器与 Buck 功率级。

**进度更新：2026-10-13**

**固件基线：`153e2b0`**（CAN、PWM、双 ADC 与电位器反馈 PI 台架测试）

当前阶段：**HW-525 / ACS758 基础功能验证已完成，正在准备真实电流信号接入 ADC。真实功率闭环尚未验证。**

## 已完成

### 固件与通信

- [x] 工程备份，固件基线已推送 GitHub。
- [x] CAN 通信测试，波特率 500 kbit/s。
- [x] 接收 `0x100` 功率指令、`0x102` 光伏/风电指令和 `0x101` 心跳，发送 `0x200` 状态反馈。
- [x] TIM3 四路 20 kHz PWM 输出测试：PA6 光伏、PA7 燃料电池、PB0 电池、PB1 风电。
- [x] ADC1 双路采样测试：PA0 模拟母线电压，PA1 模拟电流。
- [x] 光伏单路 PI 的电位器反馈方向与限幅测试；其余三路当前仍为开环控制。
- [x] 心跳超时保护：超过 1000 ms 未收到有效心跳，关闭全部 PWM、置故障码 5 并锁存，手动复位恢复。

**心跳超时关闭并锁存是当前明确保留的行为。总路线资料中的下垂控制不作为当前固件行为。**

### HW-525 / ACS758 硬件测试

- [x] 焊接 HW-525 四针排针和 IP+/IP− 功率引线。
- [x] 使用 20 Ω / 50 W 电阻搭建串联负载回路，断电实测回路约 19.74 Ω。
- [x] 模块独立供电检查，空载耗电约 22 mA。
- [x] 分离供电下完成零电流、正向电流、反向电流及撤载回零测试。
- [x] 在约 ±0.5 A 范围内，确认正向电流使输出升高、反向电流使输出降低，两路输出接近。

以下为人工台架测试记录，测试时 OUT1/OUT2 均未接入 STM32 ADC：

| 状态 | 被测电流 | 模块 VCC | OUT1 | OUT2 |
|---|---:|---:|---:|---:|
| 无电流 | 0 A | 4.957 V | 2.481 V | 2.482 V |
| 正向小电流 | +0.245 A | 4.956 V | 2.490 V | 2.492 V |
| 正向电流 | +0.491 A | 4.958 V | 2.500 V | 2.501 V |
| 撤载回零 | 0 A | 4.958 V | 2.481 V | 2.482 V |
| 反向电流 | −0.491 A | 4.957 V | 2.462 V | 2.462 V |

测试供电：电脑 USB 给 NUCLEO-F446RE 供电，开发板 5 V/GND 给传感器模块供电；台式电源单独给 IP+/IP− 与电阻组成的负载回路供电。

结合模块资料及断电电阻测量，**推断 OUT1 为直接/滤波输出，OUT2 为运放缓冲输出**。尚未完整追踪 PCB 原理图，CJMCU-758 资料与 HW-525 实物也存在版本差异，不能把输出编号对应关系视为完全确认。两路测试结果支持近似相同的直流增益。

本次测得的零点及粗估灵敏度仅用于基础功能判断，尚不是正式标定参数。早期模块与负载共用台式电源的测试数据不用于标定。本轮传感器测试未修改、编译或烧录固件。

## 正在做

**确定 OUT2 → 分压/保护 → PA1 的接入方案。**

- 以 OUT2 缓冲输出作为 ADC 输入候选，核算完整输出范围与 ADC 输入范围。
- 确定分压比例、保护和接地方式，接入前测量实际分压电压。
- 接入 PA1 前移除原电位器滑动端，避免两个信号源同时连接。
- 准备原始 ADC 观察、无电流零点标定和已知电流换算验证。

当前约 2.5 V 的输出读数不能作为直接连接 PA1 的依据；接口方案尚未完成，传感器尚未接入 ADC。
